# Actividad: Formulario de Inscripción en HTML5

## Descripción del Proyecto
Este repositorio contiene el diseño de un formulario web nativo para el registro de estudiantes interesados en participar en un taller especializado de desarrollo web. El objetivo principal de la actividad consiste en aplicar de forma exclusiva elementos estructurales y atributos de validación semántica provistos por el estándar HTML5, absteniéndose del uso de hojas de estilo (CSS) o scripts de comportamiento dinámico (JavaScript).

## Componentes Técnicos Incluidos
* **Contenedores Semánticos:** Estructuración lógica por bloques mediante etiquetas `<fieldset>` y leyendas descriptivas con `<legend>`.
* **Tipos de entrada de datos (Input types):** Uso diversificado de controles (`text`, `email`, `number`, `date`, `time`, `tel`, `url`, `radio`, `checkbox`, `file`, `color`, y `range`).
* **Reglas de Validación Nativa:** Restricciones de obligatoriedad y formato implementadas mediante los atributos `required`, `placeholder`, `min`, `max`, `minlength`, `maxlength` y expresiones regulares con `pattern`.
* **Controles de Envío:** Uso explícito de la etiqueta `<button>` configurada con tipos estandarizados `submit` y `reset`.
